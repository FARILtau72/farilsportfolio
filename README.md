# Faril Putra Pratama - Portfolio Website

Website portfolio modern yang dibangun dengan Astro, Tailwind CSS, dan Three.js.

## ✨ Fitur

- 🎨 **Desain Minimalis Modern** - UI/UX yang bersih dan menarik
- 🌟 **Animasi 3D** - Menggunakan Three.js untuk efek visual interaktif
- 🤖 **AI Chatbot** - Asisten virtual untuk menjawab pertanyaan pengunjung
- 📱 **Responsive Design** - Tampilan optimal di semua perangkat
- ⚡ **Fast Performance** - Dioptimasi untuk loading cepat
- 🌙 **Dark Theme** - Tema gelap yang nyaman di mata

## 🛠️ Tech Stack

- **Framework**: Astro
- **Styling**: Tailwind CSS
- **3D Graphics**: Three.js
- **Language**: TypeScript/JavaScript

## 🚀 Cara Menjalankan

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Jalankan development server**:
   ```bash
   npm run dev
   ```

3. **Build untuk production**:
   ```bash
   npm run build
   ```

4. **Preview production build**:
   ```bash
   npm run preview
   ```
